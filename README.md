# 叉燒 ChaShao 法規閱讀器

叉燒 ChaShao 是一套供個人長期閱讀、整理與研習法規的 Windows 桌面工具。

本儲存庫是**成品與法規資料下載頁**，只提供：

- 經驗收完成的 Windows 單一 EXE。
- `json/` 資料夾內已依工具格式整理的法規 JSON。
- 使用、下載、安全性與資料說明。

**本儲存庫不包含應用程式原始碼、開發專案、建置腳本或其他安裝包。** GitHub 自動產生的 Source code 壓縮檔只會包含這個下載儲存庫內的 EXE、README 與法規 JSON，不是工具原始碼。

## 已處理法規 JSON

[json 資料夾](https://github.com/fehu1991/ChaShaolawrader/tree/main/json)收錄可供叉燒 ChaShao 匯入的法規資料。

- 目前共 60 份 JSON，總大小約 10.1 MB。

- 可以只下載需要的法規檔案，也可以使用 GitHub 的「Code → Download ZIP」一次取得整個資料夾。

法規可能因修法而變動。這些檔案是已整理的匯入資料，不代表永遠是最新法規；使用前應與主管機關或全國法規資料庫的最新公布內容核對。

## 匯入方式

1. 下載需要的 `.json` 法規檔案。
2. 開啟叉燒 ChaShao，選擇「匯入 JSON」。
3. 選擇一份或多份法規檔案。
4. 檢查預覽中的法規名稱、版本、條文數與警告。
5. 確認正確後正式匯入並開始研讀。

如果 `json/` 沒有需要的法規，也可以在工具內開啟「AI 匯入規範」，依提示與資料格式自行準備 UTF-8 JSON。

## 主要功能

- 法規單份或批次匯入，匯入前預覽並確認內容。
- 章節與法條導覽、同頁引用展開、版本保留與條文差異比較。
- 多筆筆記、觀點段落、法條要件、概念註記、專有名詞與法律概念書。
- 跨法規搜尋、標籤與重要程度篩選。
- 研讀本預覽、保存與列印。
- 資料庫備份、每日備份、完整還原與個人筆記備份。
- 核心閱讀、搜尋、筆記、整理、備份與匯出功能可離線使用。

## 資料與隱私

- 工具啟動時不含內建法規、示範筆記或預填 AI 結果。
- 只有使用者預覽並確認的法規才會寫入本機法規庫。
- 法條原文與研習內容分開保存，AI 內容不會覆蓋原文。
- 核心功能不需要登入線上帳號。
- 建議定期使用內建備份功能，並將重要備份保存到其他磁碟。
- 本工具是研習與整理工具，不提供法律意見，也不能取代專業法律服務。
