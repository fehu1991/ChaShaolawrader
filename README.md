# 叉燒 ChaShao 法規閱讀器

叉燒 ChaShao 是一套為法規閱讀、理解、整理與長期研習設計的 Windows 桌面工具。它不是單純把法條顯示在畫面上，而是把閱讀法規時常見的工作——查找條文、追蹤引用、標記名詞、拆解要件、建立筆記、比較版本、整理研讀成果與備份資料——集中在同一個閱讀環境中。

核心閱讀與整理功能可在離線環境中使用；使用者的法規與研習資料由自己掌握。

> 本儲存庫是成品與法規資料下載頁，只提供 Windows 執行檔、已整理的法規 JSON，以及使用與安全性說明；不包含應用程式原始碼、開發專案或建置檔案。

## 這套工具能做什麼

### 專注閱讀法規

- 依法規、章節與條號快速瀏覽，不必在長篇文字中反覆尋找位置。
- 清楚呈現法規名稱、修正日期、施行日期、條號、條文內容與資料來源。
- 可加入書籤，保留稍後要重讀的重要條文。
- 深色與淺色外觀可依閱讀環境切換，適合長時間研讀。

### 直接追蹤條文引用

<img width="3817" height="2030" alt="image" src="https://github.com/user-attachments/assets/17db779b-5dda-4f45-bb2a-a60d02d604e6" />

- 辨識條文中的「前項」、「前款」及其他條文引用。
- 點選引用後，可在目前閱讀脈絡中查看所指內容，減少來回翻找。
- 引用結果與目前條文分開呈現，方便確認引用關係。

### 建立自己的法規研習資料

- 對單一條文建立多筆筆記，不必把不同問題混在同一段文字中。
- 可記錄個人觀點、爭點、疑問、案例聯想與待查事項。
- 可將條文拆解為要件，協助掌握構成條件與法律效果。
- 可標記專有名詞與法律概念，逐步建立自己的概念整理。
- 可設定標籤與重要程度，日後依主題或優先順序重新整理。

### 專有名詞與法律概念連結

<img width="3802" height="1992" alt="image" src="https://github.com/user-attachments/assets/495722e6-9454-4425-890e-bf13b5542ea4" />

<img width="3817" height="1998" alt="image" src="https://github.com/user-attachments/assets/dcdeff04-1a12-4f8d-8941-a7e918c7f1ae" />

- 同時辨識相近或互相包含的詞語，例如「保險人」與「被保險人」。
- 優先保留完整詞語，避免較短名稱切斷較長名詞。
- 點選已標記名詞，可查看對應解釋或相關整理。
- 適合跨條文累積同一法律概念的脈絡，而不是只記住單一條文中的一句話。

### 跨法規搜尋與篩選

<img width="3776" height="1994" alt="image" src="https://github.com/user-attachments/assets/43e31987-54cf-4b92-b0c9-a1bf459af8a1" />

- 搜尋條號、關鍵字、筆記、要件與專有名詞。
- 可搭配法規、標籤或重要程度縮小範圍。
- 適合尋找同一概念在不同條文或不同法規中的使用方式。

### 保留版本並比較修法差異

- 匯入同一法規的新版本時，可保留既有版本。
- 版本頁可檢視不同版本的條文變化，協助掌握新增、刪除與修改內容。
- 法條原文與個人研習內容分開保存，更新法規時不會把原文與筆記混成同一份資料。

### 整理與輸出研讀成果

- 將選定的法規、條文與研習內容整理成研讀本。
- 可在輸出前預覽內容，再保存或列印。
- 適合製作課程資料、複習資料、案件研究摘要或個人閱讀紀錄。

### 備份與還原

- 可建立完整資料備份，保存法規、版本與個人研習資料。
- 支援每日備份，降低長期使用時遺失資料的風險。
- 可另外備份個人筆記，方便保存重要研究成果。
- 還原前應確認備份來源與時間，避免以較舊資料覆蓋目前內容。

## 第一次使用

工具第一次啟動時是空的，不會預先放入法規、示範筆記或 AI 產生內容。建議依下列順序開始：

1. 下載並執行 `ChaShao-Law-Reader-1.26.1.exe`。
2. 從本儲存庫的 [json 資料夾](https://github.com/fehu1991/ChaShaolawrader/tree/main/json)下載需要的法規。
3. 在工具中選擇「匯入 JSON」。
4. 選擇一份或多份法規檔案。
5. 在匯入預覽中確認法規名稱、版本、條文數與警告。
6. 確認資料正確後再正式匯入。
7. 從左側法規與章節清單選擇條文，開始閱讀與整理。
8. 完成第一批筆記後建立一次備份。

## 完整使用方法

### 1. 匯入法規

開啟「匯入 JSON」後選擇法規檔案。工具會先顯示預覽，不會在選取檔案後立刻寫入。請特別檢查：

- 法規名稱是否正確。
- 版本或修正日期是否符合需求。
- 條文數量是否合理。
- 是否出現需要處理的警告。

只有在確認後，資料才會加入法規庫。若同時選擇多份檔案，可逐一確認各法規狀態。

### 2. 瀏覽法規與條文

從左側清單選擇法規，再展開章節或直接選擇條號。畫面中央顯示目前條文；上方路徑可確認目前所在法規、章節與條號。可以使用前後切換按鈕依序閱讀，也能從清單直接跳到指定條文。

遇到重要條文時可加入書籤，之後回到書籤或搜尋結果繼續研讀。

### 3. 查看引用關係

當條文中出現可辨識的引用文字時，點選引用即可查看所指內容。例如點選「前項」，可以立即確認同一條文前一項的文字。離開目前條文後，這類暫時閱讀標記會自動清除，不會干擾下一條文。

右側引用區會整理目前條文辨識到的引用；若沒有引用，也會明確顯示目前沒有結果。

### 4. 建立筆記與觀點

在右側切換到筆記功能，為目前條文新增筆記。建議將不同用途分開記錄，例如：

- 條文白話整理。
- 實務爭點或待確認問題。
- 課堂、書籍或判決閱讀心得。
- 與其他條文的關聯。
- 未來要補充的資料。

同一條文可以建立多筆內容，方便日後個別修改與整理。

### 5. 拆解條文要件

切換到要件功能，把條文拆成可以逐項檢查的條件。可依自己的研習目的記錄主體、行為、前提、例外、法律效果或其他判斷重點。要件整理是個人研習資料，不會改動法條原文。

### 6. 標記專有名詞與概念

在條文中選取或點選需要整理的詞語，建立專有名詞或法律概念說明。當較長名詞包含較短名詞時，工具會優先辨識完整名稱，例如「被保險人」不會只剩下「被」與另一個「保險人」標記。

可透過概念整理查看同一概念的相關內容，逐步形成跨條文的知識脈絡。

### 7. 搜尋與重新找到資料

使用上方搜尋欄輸入條號、關鍵字、筆記內容、要件或專有名詞。結果可依法規、標籤與重要程度進一步篩選。

若要長期維護資料，建議建立一致的標籤方式，例如「總則」、「程序」、「責任」、「例外」、「待查」或依個人研究主題命名。

### 8. 查看法規版本

匯入同一法規的新資料時，先確認它是否為不同版本。完成匯入後，可在版本功能中查看保留的版本並比較條文差異。

版本比較用來協助理解修法變化；正式引用法規前，仍應核對主管機關或全國法規資料庫公布的最新內容。

### 9. 製作研讀本

完成一段研習後，可將需要的法規、條文與整理內容加入研讀本。先預覽輸出結果，確認順序與內容，再保存或列印。

研讀本適合用於複習、課堂、研究、案件準備或個人歸檔，但不會取代工具內持續更新的原始研習資料。

### 10. 備份資料

完成重要匯入或大量筆記後，請建立完整備份。若每天使用，可啟用或定期執行每日備份；重要筆記也建議另外保存。

還原資料前，先確認備份建立時間及其內容是否符合需求。還原完成後應抽查法規、版本與筆記，確認資料完整。

## 建議的日常使用流程

1. 先確認需要研讀的法規版本。
2. 匯入並檢查條文資料。
3. 依章節閱讀，使用引用功能追蹤前後文。
4. 對重要條文建立書籤、筆記、要件與概念。
5. 透過搜尋與標籤回顧相關內容。
6. 遇到修法時保留新舊版本並比較差異。
7. 定期整理研讀本並建立備份。

## 資料、隱私與使用範圍

- 工具啟動時不含內建法規或示範資料。
- 只有經使用者預覽並確認的法規才會加入本機資料。
- 法條原文與個人筆記、要件、概念等研習內容分開保存。
- 核心閱讀、搜尋、筆記、整理、備份與輸出功能可離線使用。
- 工具不會自動替使用者更新法規。
- 使用者應自行保存備份，並核對需要正式引用的法規版本。
- 本工具用於法規研習與個人整理，不提供法律意見，也不能取代律師或其他專業法律服務。
