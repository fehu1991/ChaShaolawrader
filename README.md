# 叉燒 ChaShao 法規閱讀器

叉燒 ChaShao 是一套供個人長期閱讀、整理與研習法規的 Windows 桌面工具。

本儲存庫是官方下載頁，只提供已完成驗收的 Windows 單一 EXE 與發布說明，不公開專案原始碼。

## 主要功能

- 匯入自己準備並確認過的法規資料，匯入前先預覽名稱、版本、條文數與警告。
- 依章節與條號閱讀法規，在同一頁展開引用，並比較不同版本的條文差異。
- 建立多筆研習筆記、觀點段落、法條要件、概念註記與專有名詞解釋。
- 將跨法規的法律概念集中整理成概念書。
- 搜尋法條與個人研習內容，搭配標籤、重要程度與內容類型篩選。
- 選擇法條與筆記製作研讀本，預覽後保存或列印。
- 提供資料庫備份、每日備份、完整還原、個人筆記備份與處理紀錄。
- 核心閱讀、搜尋、筆記、整理、備份與匯出功能可離線使用。

## 下載與執行

1. 前往 [Releases](https://github.com/fehu1991/ChaShaolawrader/releases)。
2. 下載最新版本的 `ChaShao-Law-Reader-版本號.exe`。
3. 建議先核對發布頁公布的 SHA-256。
4. 直接執行 EXE；不需要安裝，也不會另外建立 MSI 或其他安裝程式。

### Windows 安全性提醒

目前 EXE 尚未加上商業數位簽章，因此 Windows SmartScreen 可能顯示「Windows 已保護您的電腦」。請先確認檔案來自本儲存庫，並核對 SHA-256；確認相符後，才選擇「其他資訊」與「仍要執行」。

請勿執行來源不明或雜湊值不同的檔案。

## 第一次使用

工具啟動時不含任何內建法規、示範筆記或預填 AI 結果。

1. 在工具內開啟「AI 匯入規範」。
2. 複製法規處理提示與資料格式範例。
3. 將提示與法規原文交給 AI 整理，取得 UTF-8 JSON。
4. 回到工具選擇 JSON，檢查預覽結果。
5. 確認內容正確後才正式匯入並開始研讀。

工具不會自動下載法規，也不替使用者判斷內容是否為最新版本。法條原文與研習內容分開保存，AI 內容不會覆蓋原文。

## 資料與隱私

- 正式法規、版本、條文、索引與研習資料保存在使用者本機。
- 核心功能不需要登入線上帳號。
- 建議定期使用內建備份功能，並將重要備份保存到其他磁碟。
- 本工具是研習與整理工具，不提供法律意見，也不能取代專業法律服務。

## 維護者建置說明

> 本下載儲存庫不包含原始碼。以下流程適用於持有完整本機來源樹的維護者。

### 建置需求

- Windows
- Node.js 22 或更新版本，並包含 npm
- Rust stable、Cargo 與 Windows MSVC 編譯工具鏈
- Microsoft Edge WebView2 Runtime

### 建置方式

在完整來源碼根目錄直接執行：

```text
build-windows.cmd
```

建置流程會依序：

1. 檢查 JavaScript 相依套件。
2. 核對產品版本並產生法規資料驗證器。
3. 準備 Windows 應用程式圖示。
4. 執行型別檢查。
5. 執行完整自動化測試。
6. 建置 Tauri 單一 EXE，不建立安裝包。
7. 將唯一發布檔案收集到版本資料夾。
8. 清除可重新產生的暫存建置資料。

成功後輸出位置：

```text
release/版本號/ChaShao-Law-Reader-版本號.exe
```

每次公開前應再次確認產品版本、測試結果、EXE 內嵌版本、檔案大小與 SHA-256。
